# Ashan Willaddarage — Engineering Portfolio

A responsive static portfolio website hosted on Cloudflare Pages at https://ashanwilladdarage.com/.

## Files
- `index.html` — homepage and content
- `styles.css` — dark navy responsive design
- `script.js` — mobile navigation and copyright year

## Publish
Upload these three website files to the root of the existing `ashnz/engineering-portfolio` GitHub repository on its production branch (`main`, if configured). Cloudflare Pages will automatically deploy the changes.

If build settings need checking: framework `None`, build command `exit 0`, output directory `.` for root-level files.

## Customize before sharing
- Replace the placeholder LinkedIn link (`https://www.linkedin.com/`) with your own profile URL, or remove the button.
- Review project descriptions to ensure they accurately reflect completed versus ongoing work.
- Add your own images, project case studies, measured results and CV when ready.
- GitHub profile currently links to `https://github.com/ashnz`; adjust if desired.

No Node.js, npm, React, or paid service required. The Google Fonts stylesheet is optional and loads remotely; fallback fonts are included.
